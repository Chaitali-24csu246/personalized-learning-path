# Content and runtime provenance

The course prose, questions and reference implementations were authored for this project with AI assistance and checked by executing examples and expected outputs. Educator review of pedagogical quality and difficulty remains appropriate. Common algorithms are described in original wording. No GeeksforGeeks content was scraped or copied.

Further-reading links point to the official Python tutorial: https://docs.python.org/3/tutorial/

Python in the browser uses Pyodide 0.27.7, loaded from https://cdn.jsdelivr.net/pyodide/v0.27.7/full/ . Pyodide and its bundled components retain their upstream licences; the runtime is not included in this ZIP. Project: https://github.com/pyodide/pyodide . The authored app does not require third-party JavaScript UI libraries.

The GitHub Actions workflow follows GitHub Pages’ documented custom deployment process: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages . CI checks must pass before the deployment job is eligible to run.
